# Earlier Power BI dashboard

Built on the Kaggle copy of the DfT road safety data (2005 to 2014), before the
pipeline in `src/` was written. It does not use the CSVs in `dashboard/data`,
which come from the newer DfT release (2005 to 2019). CY means 2014, the
latest year in that data. The .pbix file (83 MB) is not included.
